# Gロガー

iPhoneのSafariで使う、Gセンサー（加速度）とGPSの記録アプリです。単一HTMLファイル（`index.html`）で動作します。

公開URL（GitHub Pages）: https://hanaphoto.github.io/g-logger/

## 機能（4タブ）

1. **走行G** - 前後G・横G・上下Gの数値表示、Gの軌跡（円グラフ）、直近10秒の折れ線グラフ、最大加速・減速・左右の表示。スマホの向き選択、表示範囲選択（0.5〜2G）、ゼロ点設定、記録開始／停止、CSVのコピー・共有・消去。
2. **衝撃・振動** - 重力を除いた加速度の大きさ（現在値・最大値）。しきい値を超えた回数をカウントし、時刻とピークをイベント一覧に表示。
3. **ルート** - GPSと連動して走行ルートを地図風に描画。線の色は速度またはGで切り替え。現在速度・走行距離・最高速度を表示。GPXのコピー・共有に対応。
4. **G+ルート** - 走行Gとルートを同時表示。CSVにGと位置・速度が同じ行にまとまります。

## 使い方

1. iPhoneのSafariで公開URLを開く
2. 初回は「モーションと方向へのアクセス」を許可する（ルート使用時は位置情報も許可）
3. 車両等にスマホを固定し、停車状態で「ゼロ点設定」を押してから「記録開始」

## 注意

- 画面を消したり別アプリに切り替えると記録が止まります（スリープ防止機能入りですが、長時間記録時は画面点灯のままを推奨）
- 記録頻度は最大60Hz程度、GPS更新は約1秒ごと（精度50m超の点は除外）
- Claudeで作成したアプリで、実機での検証はこれから行います
